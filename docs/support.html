Vanliga frågor

Hur lås jag upp en modul?

Tryck på modulen på startskärmen. Du får då upp en betalskärm där du kan låsa upp paketet. Vid köpet behöver du verifiera med Face ID, Touch ID eller ditt Apple-ID-lösenord.

Hur återställer jag tidigare köp på en ny iPhone?

Logga in med samma Apple-ID som vid det ursprungliga köpet. Öppna en låst modul i Rita och tryck på "Återställ köp". Alla tidigare köp aktiveras automatiskt.

Hur avslutar jag prenumerationen?

Öppna iPhones inställningar → tryck på ditt namn högst upp → "Prenumerationer" → välj Rita → "Avbryt prenumeration". Den fortsätter fungera tills nuvarande period löper ut.

Varför kan inte mitt barn trycka på knappen för köp?

Det är meningen. Rita har en föräldrarspärr som ber dig lösa en enkel matematikuppgift innan ett köp kan genomföras. Detta skyddar mot oavsiktliga köp.

Sparar appen barnens foton?

Nej. När du tar ett foto för "Förvandla ett kort" bearbetas bilden direkt på enheten. Inget skickas till någon server och fotot sparas inte permanent av Rita. Den slutgiltiga målarbilden sparas endast om du själv väljer att exportera eller dela den.

Mina sparade teckningar försvann efter att jag avinstallerat appen

Sparade teckningar lagras endast lokalt på enheten. När appen avinstalleras tas de tyvärr bort. Tips: använd dela-knappen för att spara dina favoriter i fotobiblioteket innan avinstallation.

Vilka iPhones och iPads stöds?

Rita kräver iOS 14.0 eller senare. Appen är optimerad för iPhone och iPad.

Vi älskar feedback! Mejla din idé till alexander.bergqvist@gmail.com så ser vi om den kan komma med i en framtida uppdatering.
